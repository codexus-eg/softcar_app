# SoftCar Shuttle — Passenger App (iOS)

This folder contains the complete **iOS source** for the SoftCar Shuttle passenger
app (Flutter). It is intended to be opened, configured, and submitted to the
**Apple App Store** by an Apple Developer.

## Identity

- iOS **Bundle Identifier**: `com.softcar.passengersss`
- Display name: SoftCar Shuttle
- Firebase project: `softcar-shuttle` (project number `1034556386631`)
- Android applicationId (for reference): `com.softcar.passengersss`
- App version: `1.5.2+2026083102`

## Prerequisites

1. A paid **Apple Developer Program** account.
2. A Mac with **Xcode** (latest stable) and **Flutter SDK** installed.
3. Firebase `GoogleService-Info.plist` for this app (see below).

## Required: Firebase iOS configuration (PUSH NOTIFICATIONS)

The repo intentionally does **not** include a valid `GoogleService-Info.plist`
(it must be generated per-bundle-id in the Firebase console). Do this:

1. Go to the [Firebase Console](https://console.firebase.google.com) and open
   project **softcar-shuttle**.
2. **Project settings → Your apps → Add app → iOS**.
3. iOS bundle ID: `com.softcar.passengersss`
   - (optionally set App Store ID when you have the App Store Connect app).
4. Click **Register app**, then **Download GoogleService-Info.plist**.
5. Move the downloaded `GoogleService-Info.plist` into
   `ios/Runner/GoogleService-Info.plist` (replacing the placeholder/template if present).
6. A valid plist fills in `GOOGLE_APP_ID`, `API_KEY`, `BUNDLE_ID`, etc. The
   template file `ios/Runner/GoogleService-Info.plist.template` is provided as a
   reference only.

> Important: the app uses Firebase **Cloud Messaging**. Push entitlements
> (Apple Push Notification service / APNs) must also be enabled in the Xcode
> **Signing & Capabilities** for the Runner target, and verified in Apple
> Developer → Certificates, Identifiers & Profiles → Identifiers → your App ID.

## Build steps (macOS only)

```bash
flutter pub get
cd ios
pod install
cd ..
flutter build ios --release --no-codesign   # produces ios/build/ios/iphoneos/*.app
```

Then in Xcode, open `ios/Runner.xcworkspace`, select a development team under
**Signing & Capabilities**, and archive (`Product → Archive`) to create the build
for App Store Connect.

## WebSocket / server note

The app points at the production backend `https://softcarshuttle.com`. For
development builds, update the API base URL and WebSocket URL in the Flutter
config (`lib/`) as needed.
